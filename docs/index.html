Other MHGU Apps

Companion fan tools by the same author. Each opens in a new tab.

  • Quest Randomizer Rolls random quests when you can't decide what to hunt.
  • Collection Tracker Tracks which weapons, armor and Palico gear you own, and what it costs to finish them.
  • Equipment Box Mirrors the in-game box — 2000 hunter slots and 1000 Palico — so you can plan where things sit.
  • Quest Bingo Builds a bingo card of hunting goals, with a shareable seed so a group can race the same board.
  • Hunting Log Keeps a running record of your hunts — what you were after, what you wore, who came along.
  • Zenny Gauntlet A scored challenge run — fail a hunt or get carted and you lose that weapon/style combo for the rest of the run.
  • Set Builder you are here Assemble a full set by hand and see exactly which skills it activates.
  • Weapon Trees Browse every weapon upgrade tree, with full stats on any node you click.
  • Challenge Run A permadeath challenge run — start from a root weapon, lose it on any quest failure, clear every Key Quest.
  • Charm Farm A Clicker/Idle game about beating up various Brachydios until you finally get the desired God Charms you always wanted.
  • Talisman Bingo A bingo card of talisman conditions — keep drawing charms until one finally fills the line you needed.

About / Attributions

An unofficial, non-commercial fan tool for planning MHGU armor sets by hand. Pick a weapon, five armor pieces, decorations and a talisman; the builder totals defense, resistances and slots and shows every skill the set activates — including negative skills, Torso Up and the compound Soul skills.

Development: Built by the author with substantial help from Claude Code, Anthropic's AI coding tool. Most of the code, the data generator and this page were written with AI assistance, reviewed and directed by the author.

Armor data: extracted from the game's own data tables by the Collection Tracker project (see its notices for the full toolchain credits).

Weapon stats and talisman tables: derived from Kiranico.

Skill thresholds, decorations and English names: MHGUDB-iOS (MIT) & gatheringhallstudios community database.

Equipment icons: monsterhunterwiki.org — licensed under CC BY-SA 4.0; adaptations shared under the same licence.

Menu textures and font: carried over from the sibling MHGU apps.

Monster Hunter content is owned by Capcom. This tool is not affiliated with or endorsed by Capcom.
