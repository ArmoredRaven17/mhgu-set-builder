## Game Data

The data under `docs/data/` is generated by
[scripts/build-data.mjs](scripts/build-data.mjs) from the following sources,
none of which are redistributed here in their original form:

### MHGU Collection Tracker (same author)

Armor stats, resistances, decoration slots, skill points and per-level
defense, plus weapon stat tables, are taken from the sibling
[mhgu-collection-tracker](https://github.com/ArmoredRaven17/mhgu-collection-tracker)
project's generated data. That project extracts armor data directly from
Monster Hunter Generations Ultimate's own data tables (dumped by the author
from a personally-owned cartridge) and sources weapon tables from Kiranico —
see its NOTICE.md for the full extraction-toolchain credits.

### Kiranico (https://mhgu.kiranico.com/)

Weapon stat tables and the talisman charm-roll tables originate from
Kiranico's MHGU database. Kiranico does not publish a formal data license;
this attribution is offered as courtesy acknowledgment of their fan-database
work. If the maintainers of Kiranico object to this use, please open an
issue and the affected data will be reviewed or removed.

### gatheringhallstudios / JoeLago community database

Skill trees, skill activation thresholds and descriptions, decoration data,
and all English naming derive from the MHGU database (`mhgu.db`) bundled in
[JoeLago/MHGUDB-iOS](https://github.com/JoeLago/MHGUDB-iOS) (MIT-licensed),
built on the community database from
[gatheringhallstudios/MHGenDatabase](https://github.com/gatheringhallstudios/MHGenDatabase).
Only factual data is extracted and re-emitted in this project's own JSON
schema; no source code, schema, or image assets from those projects are
redistributed.

### Athena's Armor Set Search for MHGU

[Athena's Armor Set Search](https://github.com/AthenaADP/MHGU-ASS) (MIT) is
used during data generation in two ways:

- **Armor availability** — at which Gathering-Hall (HR) star and Village star
  each armor piece becomes craftable, and whether both conditions or either
  one is required. This is used to power the search's progression filter.
  The game's own data tables do not record it and the community database
  cannot supply it, so Athena's hand-transcribed availability table is the
  only reliable source for this fact.
- **Compound-skill coverage**, as a cross-check.

Only these factual values are read, and only at build time; no data files,
source code, or assets from that program are redistributed here.

### MHXX / GU Speedrun Archive

`scripts/ta-sets.json` holds the armor skill lists from the community
**MHXX_GU Speedrun Archive** spreadsheet — 332 sets that runners actually
built and used. They serve only as test queries for the search
(`scripts/test-ta-sets.mjs`), on the principle that real sets test it better
than anything invented for the purpose. Skill names are normalised to this
project's in-game names; nothing else from the archive is reproduced.

derived variants bundled here are shared under the same licence. Underlying
