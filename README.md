# MHGU Set Builder

A manual armor set builder for **Monster Hunter Generations Ultimate**. Pick a
weapon, five armor pieces, decorations and a talisman; the app totals defense,
resistances and slots, and shows which skills the set activates — including
negative skills, Torso Up multiplication and the compound "Soul" skills.

Live: https://armoredraven17.github.io/mhgu-set-builder/

"Manual" means you choose every piece yourself. This is a planning surface,
not an automatic set searcher — for that, use Athena's Armor Set Search.

## How it fits the family

Static site served from `docs/`, no build step, deployed to GitHub Pages on
push to `master`. It shares one save document with the
[Collection Tracker](https://github.com/ArmoredRaven17/mhgu-collection-tracker)
and the [Equipment Box](https://github.com/ArmoredRaven17/mhgu-equipment-box):
this app owns the top-level `sets` key and carries every other key through
untouched, so all three apps can read and write the same `mhgu-collection.json`.

## Data

All game data under `docs/data/` is generated by `scripts/build-data.mjs`
(Node ≥ 22, no dependencies) from local sources — see the header of that
script and [NOTICE.md](NOTICE.md) for provenance. Nothing under `docs/data/`
is edited by hand.

```
node scripts/build-data.mjs
```

Skill-tree ids are the game's own and are used consistently across files:
armor skills, decorations, charm tables, activation thresholds and soul
expansions all key on the same id space.

## Local development

```
python -m http.server 8128 --directory docs
```

Data is `fetch()`ed, so the site must be served — `file://` won't work.
